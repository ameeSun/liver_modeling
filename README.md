# Liver Modeling
1. This project uses liver data from the Indian Liver Patient Record (https://www.kaggle.com/datasets/uciml/indian-liver-patient-records) to diagnose liver disease in patients using machine learning
2. The most accurate model was Random Forest Classifier which yielded an accuracy of 99.94%
3. Purpose: Use prediction models to create a more efficient and accurate moethod of diagnosing liver disease in patients
# Instructions
1. Run 'main' --> this will train and test the model using the liver data, outputting the accuracy of the model
2. Run 'input' --> this will allow users to input liver data and recieve a diagnosis
